# US107 - Notify report thread via condition variables upon safety violation detection

## 1. Objetivo

Quando a thread de deteção de violações de segurança identifica um conflito na memória partilhada, deve notificar imediatamente a thread de geração de relatório através de condition variables, para que o evento seja registado em tempo real.

---

## 2. Critérios de aceitação

| Critério | Implementação |
| -------- | ------------- |
| Thread de deteção monitoriza shared memory | `safety_detection_thread()` em `simulation_threads.c` |
| Notificação via condition variables | `pthread_cond_signal(&ctx->violation_cond)` após deteção |
| Thread de relatório aguarda e processa imediatamente | `report_generation_thread()` com `pthread_cond_wait()` |
| Mutex para notificação thread-safe | `ctx->report_mutex` protege `SafetyLog` e a condição |

---

## 3. Arquitetura

### Thread de deteção (`safety_detection_thread`)

1. Aguarda alterações na memória partilhada (`pthread_cond_wait` em `shared->pthread_cond`).
2. Invoca `safety_check_shared()` para analisar conflitos entre voos.
3. Se existirem violações novas, bloqueia `report_mutex`, regista no `SafetyLog` e faz `pthread_cond_signal`.

### Thread de relatório (`report_generation_thread`)

1. Aguarda em `pthread_cond_wait(&violation_cond, &report_mutex)` enquanto não houver eventos por processar.
2. Quando acordada, regista cada violação em stderr e no ficheiro `simulation_violations.log`.
3. Incrementa `violations_reported` para evitar reprocessamento.

---

| Ficheiro | Papel |
| -------- | ----- |
| `simulation_threads.c` | Threads US106/US107 |

---

## 5. Sincronização

```
flight process ──► shared memory ──► pthread_cond_signal(shared)
                                           │
                                           ▼
                              safety_detection_thread
                                           │
                         report_mutex + violation_cond
                                           │
                                           ▼
                              report_generation_thread
                                           │
                                           ▼
                              simulation_violations.log
```

---

## 6. Testes

- `tests/test_simulation_threads.c` — verifica notificação condicional entre threads.
- `./tests/run_tests.sh` — executa todos os testes unitários.

---

## 7. Execução

```bash
cd scomp
make
./flight_simulator --area 39 43 -9 -3 --start 0 --end 3600 --step 60 \
  --weather clear --safety-min-sep 3 --safety-min-alt 300 \
  --perf-max-flights 10 --flight data/Flight_Plan_v0a.json
```

Durante a simulação, mensagens `[US107 report]` aparecem em stderr quando ocorrem violações. O log em tempo real fica em `simulation_violations.log`.
