# Glossary

| **TEA (EN)**                       | **TEA (PT)**                              | **Description (EN)**                                                                                                                                  | **Descrição (PT)**                                                                                                                                 |
|------------------------------------|-------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------|
| **Admin**                          | **Administrador**                         | Internal AISafe user responsible for managing users, permissions and backoffice access.                                                               | Utilizador interno da AISafe responsável por gerir utilizadores, permissões e acessos ao backoffice.                                               |
| **Aircraft**                       | **Aeronave**                              | A real aircraft belonging to the fleet of an air transport company. Each aircraft uses one aircraft model and one engine model.                       | Aeronave real pertencente à frota de uma companhia aérea. Cada aeronave utiliza um modelo de aeronave e um modelo de motor.                        |
| **Aircraft Model**                 | **Modelo de Aeronave**                    | Commercial aircraft specification defining the operational and physical characteristics shared by multiple aircraft.                                  | Especificação comercial de aeronave que define as características operacionais e físicas partilhadas por várias aeronaves.                         |
| **Air Control Area**               | **Área de Controlo Aéreo**                | Controlled geographic area where flights are monitored and simulated.                                                                                 | Área geográfica controlada onde os voos são monitorizados e simulados.                                                                             |
| **Air Transport Company**          | **Companhia Aérea**                       | Airline company responsible for operating flights, aircraft and pilots.                                                                               | Companhia aérea responsável por operar voos, aeronaves e pilotos.                                                                                  |
| **Airport**                        | **Aeroporto**                             | Airport registered in the system and associated with a single air control area. Identified by IATA and ICAO codes.                                    | Aeroporto registado no sistema e associado a uma única área de controlo aéreo. Identificado por códigos IATA e ICAO.                               |
| **Authentication**                 | **Autenticação**                          | Process of validating the identity of a system user.                                                                                                  | Processo de validação da identidade de um utilizador do sistema.                                                                                   |
| **Authorization**                  | **Autorização**                           | Process of granting access permissions according to the user role.                                                                                    | Processo de atribuição de permissões de acesso de acordo com o papel do utilizador.                                                                |
| **Backoffice Operator**            | **Operador de Backoffice**                | AISafe collaborator responsible for maintaining operational and configuration data in the system.                                                     | Colaborador da AISafe responsável por manter dados operacionais e de configuração do sistema.                                                      |
| **Certified Engine**               | **Motor Certificado**                     | Engine model approved for use in a specific aircraft model.                                                                                           | Modelo de motor aprovado para utilização num modelo específico de aeronave.                                                                        |
| **Customer**                       | **Cliente**                               | Business entity using AISafe services, such as an Air Transport Company or an Air Control Area.                                                       | Entidade de negócio que utiliza os serviços da AISafe, como uma Companhia Aérea ou uma Área de Controlo Aéreo.                                     |
| **Customer Collaborator**          | **Colaborador de Cliente**                | User associated with a customer entity.                                                                                                               | Utilizador associado a uma entidade cliente.                                                                                                       |
| **DSL (Domain Specific Language)** | **DSL (Linguagem Específica de Domínio)** | Formal language used to describe and validate flight plans.                                                                                           | Linguagem formal utilizada para descrever e validar planos de voo.                                                                                 |
| **Engine Model**                   | **Modelo de Motor**                       | Commercial engine specification that may be certified for aircraft models.                                                                            | Especificação comercial de motor que pode ser certificada para modelos de aeronave.                                                                |
| **Flight**                         | **Voo**                                   | Operational and scheduled execution of a flight route. A flight contains operational information such as date, aircraft, crew and load.               | Execução operacional e calendarizada de uma rota de voo. Um voo contém informação operacional como data, aeronave, tripulação e carga.             |
| **Flight Control Operator**        | **Operador de Controlo Aéreo**            | User responsible for validating and simulating flights inside an air control area.                                                                    | Utilizador responsável por validar e simular voos dentro de uma área de controlo aéreo.                                                            |
| **Flight Designator**              | **Designador de Voo**                     | Unique operational identifier associated with a flight.                                                                                               | Identificador operacional único associado a um voo.                                                                                                |
| **Flight Leg**                     | **Trecho de Voo**                         | Non-stop section of a flight between two airports.                                                                                                    | Secção sem escalas de um voo entre dois aeroportos.                                                                                                |
| **Flight Plan**                    | **Plano de Voo**                          | Operational document describing how a flight will be executed, including legs, routes and fuel information.                                           | Documento operacional que descreve como um voo será executado, incluindo trechos, rotas e informação de combustível.                               |
| **Flight Route**                   | **Rota de Voo**                           | Commercial route defined by an air transport company between two airports. Represents the reusable route definition, not the scheduled flight itself. | Rota comercial definida por uma companhia aérea entre dois aeroportos. Representa a definição reutilizável da rota, não o voo calendarizado em si. |
| **Flight Schedule Entry**          | **Entrada de Horário de Voo**             | Scheduling information associated with recurring regular flights.                                                                                     | Informação de calendarização associada a voos regulares recorrentes.                                                                               |
| **Flight Type**                    | **Tipo de Voo**                           | Operational classification of a flight.                                                                                                               | Classificação operacional de um voo.                                                                                                               |
| **Fuel Information**               | **Informação de Combustível**             | Fuel data associated with a flight leg or flight plan.                                                                                                | Dados de combustível associados a um trecho de voo ou plano de voo.                                                                                |
| **IATA Code**                      | **Código IATA**                           | Standard short identifier used for airports or airlines.                                                                                              | Identificador curto normalizado utilizado para aeroportos ou companhias aéreas.                                                                    |
| **ICAO Code**                      | **Código ICAO**                           | Standard operational identifier used for airports or airlines.                                                                                        | Identificador operacional normalizado utilizado para aeroportos ou companhias aéreas.                                                              |
| **Manufacturer**                   | **Fabricante**                            | Company responsible for manufacturing aircraft and/or engines.                                                                                        | Empresa responsável pelo fabrico de aeronaves e/ou motores.                                                                                        |
| **Node**                           | **Nó**                                    | Connection point between flight segments.                                                                                                             | Ponto de ligação entre segmentos de voo.                                                                                                           |
| **Pilot**                          | **Piloto**                                | User responsible for creating and managing flight plans.                                                                                              | Utilizador responsável por criar e gerir planos de voo.                                                                                            |
| **Pilot Certification**            | **Certificação de Piloto**                | Authorization allowing a pilot to operate a specific aircraft model.                                                                                  | Autorização que permite a um piloto operar um modelo específico de aeronave.                                                                       |
| **Regular Flight**                 | **Voo Regular**                           | Recurring scheduled flight operated repeatedly over time.                                                                                             | Voo recorrente calendarizado e operado repetidamente ao longo do tempo.                                                                            |
| **Route**                          | **Rota**                                  | Path followed during a flight, composed of segments and junctions.                                                                                    | Caminho seguido durante um voo, composto por segmentos e nós de ligação.                                                                           |
| **Safety Violation**               | **Violação de Segurança**                 | Situation where air safety constraints may be violated during simulation.                                                                             | Situação em que restrições de segurança aérea podem ser violadas durante a simulação.                                                              |
| **Segment**                        | **Segmento**                              | Linear path between two coordinates inside a route definition.                                                                                        | Caminho linear entre duas coordenadas dentro da definição de uma rota.                                                                             |
| **Simulation**                     | **Simulação**                             | Execution request used to simulate flights and analyse operational or safety conditions.                                                              | Pedido de execução utilizado para simular voos e analisar condições operacionais ou de segurança.                                                  |
| **Simulation Report**              | **Relatório de Simulação**                | Final persisted result produced after a simulation execution.                                                                                         | Resultado final persistido produzido após a execução de uma simulação.                                                                             |
| **Test Flight**                    | **Voo de Teste**                          | Simulated execution of a flight plan to validate operational consistency and safety.                                                                  | Execução simulada de um plano de voo para validar consistência operacional e segurança.                                                            |
| **User**                           | **Utilizador**                            | Person authenticated in the system with permission to execute functionalities.                                                                        | Pessoa autenticada no sistema com permissão para executar funcionalidades.                                                                         |
| **Weather Data**                   | **Dados Meteorológicos**                  | Meteorological information associated with flights and air control areas.                                                                             | Informação meteorológica associada a voos e áreas de controlo aéreo.                                                                               |
| **Weather Import Batch**           | **Importação de Dados Meteorológicos**    | Batch operation used to import weather information into the system.                                                                                   | Operação em lote utilizada para importar informação meteorológica para o sistema.                                                                  |
| **Weather Person**                 | **Responsável Meteorológico**             | User responsible for managing weather information in the system.                                                                                      | Utilizador responsável por gerir informação meteorológica no sistema.                                                                              |
| **Weather Source**                 | **Fonte Meteorológica**                   | External provider of weather information.                                                                                                             | Fonte externa de informação meteorológica.                                                                                                         |
