# Documento de estudo - US030, US031, US032

## US030 - Authentication and Authorization

### `domain/usermanagement/SEM4PIPasswordPolicy.java`
- Politica de passwords do projeto (tamanho minimo, digito e maiuscula).
- Usada na validacao de alteracao de password e criacao de utilizadores.

### `domain/usermanagement/SEM4PIRoles.java`
- Define os roles do sistema (ex.: ADMIN, BACKOFFICE_OPERATOR).
- Usado pela camada aplicacional para autorizacao.

### `domain/usermanagement/UserBuilderHelper.java`
- Ajuda a criar `SystemUser` com a policy e roles definidos.

### `application/service/usermanagment/UserAccessService.java`
- Valida se o utilizador pode aceder ao sistema.
- Consulta o `UserRepository` do framework e verifica `SystemUser.active`.

### `application/controller/usermanagement/AuthenticationController.java`
- Coordena login, logout e alteracao de password.
- Usa `AuthenticationService`/`AuthorizationService` do framework.
- Aplica policy e bloqueia acesso a utilizadores inativos.

### `presentation/authz/LoginUI.java`
- Recolhe credenciais e chama o controller para autenticar.

### `presentation/authz/LogoutUI.java`
- Termina a sessao atual via controller.

### `presentation/authz/ChangePasswordUI.java`
- Recolhe password atual/nova e chama o controller.

### `presentation/authz/LoginAction.java`
- Acao de menu que dispara a UI de login.

### `presentation/authz/LogoutAction.java`
- Acao de menu que dispara a UI de logout.

### `infrastructure/persistence/PersistenceContext.java`
- Ponto central de acesso a repositorios (inclui `users()` do framework).

## US031 - Register Backoffice Users

### `domain/usermanagement/BackofficeUser.java`
- Entidade de perfil de negocio do utilizador backoffice.

### `domain/usermanagement/SEM4PIPasswordPolicy.java`
- Policy usada na validacao de passwords durante o registo.

### `domain/usermanagement/SEM4PIRoles.java`
- Define o role atribuido no registo (`BACKOFFICE_OPERATOR`).

### `domain/usermanagement/UserBuilderHelper.java`
- Cria o `SystemUser` com policy e roles.

### `domain/usermanagement/BackofficeUserRepository.java`
- Repositorio do perfil backoffice (unicidade de username/email).

### `application/service/usermanagment/RegisterBackofficeUserService.java`
- Coordena a criacao do `SystemUser` e do `BackofficeUser`.
- Garante unicidade de username/email e persiste ambos.

### `application/controller/usermanagement/RegisterBackofficeUserController.java`
- Garante permissao ADMIN e valida precondicoes.
- Fornece validacoes rapidas para a UI.
- Delegacao final para o service.

### `presentation/usermanagement/RegisterBackofficeUserUI.java`
- Recolhe dados do utilizador e faz validacoes basicas.
- Invoca o controller para registar.

### `infrastructure/persistence/JPA/JpaBackofficeUserRepository.java`
- Implementacao JPA do repositorio de backoffice users.

### `infrastructure/persistence/memory/InMemoryBackofficeUserRepository.java`
- Implementacao in-memory do repositorio de backoffice users.

### `infrastructure/bootstrap/MasterUsersBootstrapper.java`
- Bootstrap de utilizadores default (admin/backoffice).

## US032 - Disable/Enable Backoffice Users

### `domain/usermanagement/BackofficeUser.java`
- Perfil de negocio usado para listar utilizadores.

### `domain/usermanagement/SEM4PIRoles.java`
- Role ADMIN exigido para operacoes de enable/disable.

### `domain/usermanagement/BackofficeUserRepository.java`
- Fonte de perfis para listagem de utilizadores.

### `application/service/usermanagment/UserStatusService.java`
- Lista utilizadores com estado ativo.
- Ativa/desativa `SystemUser` e impede auto-desativacao do admin.

### `application/controller/usermanagement/ManageBackofficeUserStatusController.java`
- Encapsula chamadas ao service para a UI.

### `presentation/usermanagement/ManageBackofficeUserStatusUI.java`
- Lista utilizadores e permite enable/disable.

### `presentation/usermanagement/ListBackofficeUsersUI.java`
- Lista utilizadores e respetivo estado (somente leitura).

### `infrastructure/persistence/JPA/JpaBackofficeUserRepository.java`
- Implementacao JPA usada para obter perfis.

### `infrastructure/persistence/memory/InMemoryBackofficeUserRepository.java`
- Implementacao in-memory usada para obter perfis.

### `infrastructure/persistence/PersistenceContext.java`
- Fornece acesso a `users()` (framework) e `backofficeUsers()`.
